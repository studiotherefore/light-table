# Security

Light Table runs a small web server on your Mac for the board. It listens on `127.0.0.1` only, so other machines can't reach it, and it refuses requests that come from other websites. It reads your project folders and writes only to your table folder.

If you find a way around any of that, or anything else that could expose someone's files or notes, please report it privately: on GitHub, open the repo's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it.

This is a personal project maintained in spare time. Reports are read and fixed as soon as possible, without a fixed response time.
